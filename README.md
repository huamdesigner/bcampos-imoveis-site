# BCampos Imóveis — Site

Projeto inicial para o site institucional da BCampos Imóveis.

## Estrutura

```text
bcampos-imoveis-site/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── img/
```

## Como abrir no VS Code

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra o `index.html`.
4. Se tiver a extensão Live Server, clique com o botão direito no `index.html` e selecione **Open with Live Server**.
